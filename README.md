# 🔢 Multiplication Table

A simple and interactive web project for learning multiplication tables.

## 📌 About the Project

This project helps children learn multiplication tables in a simple and fun way.

The user enters a number and clicks the **Run 🚀** button. The website then generates the multiplication table from **1 to 10**.

The project has a colorful and child-friendly design to make learning more enjoyable.

## ✨ Features

- 🔢 Enter any number
- 🚀 Generate multiplication table with one click
- 📚 Table from 1 to 10
- 🎨 Colorful and attractive UI
- 🧒 Easy for children to use
- 📱 Responsive design
- 💡 Learning tip for students

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
